# خادم منصة استثمار المستقبل AI — نسخة تجريبية

هذه الحزمة تضيف خادمًا وقاعدة بيانات SQLite حقيقية للتسجيل وتسجيل الدخول وأكواد الدعوة وعدّ المسجلين عبر كل كود. **لا تتضمن استقبال أموال أو أرصدة قابلة للسحب أو تنفيذ استثمارات أو دفع مكافآت.** المكافأة المذكورة (5000 دج بعد 10 دعوات) تُعرض كاقتراح غير مفعّل، وليست وعدًا بالدفع.

## المتطلبات
- Node.js 20 أو أحدث.
- اتصال بالإنترنت لتنزيل المكتبات عند التثبيت.

## التشغيل محليًا
1. فك ضغط الملف.
2. افتح الطرفية داخل مجلد المشروع.
3. ثبّت المكتبات: `npm install`
4. أنشئ أسرارًا طويلة عشوائية، ثم عيّن المتغيرات البيئية قبل التشغيل. مثال Linux/macOS:
   ```bash
   export JWT_SECRET="ضع_هنا_سرًا_عشوائيًا_طويلًا_لا_يقل_عن_32_حرفًا"
   export ADMIN_API_KEY="ضع_هنا_مفتاح_إدارة_مختلفًا_وطويلًا"
   npm start
   ```
   في Windows PowerShell استخدم `$env:JWT_SECRET="..."` و`$env:ADMIN_API_KEY="..."` بدل `export`.
5. افتح `http://localhost:3000`.

تُنشأ قاعدة البيانات `data.sqlite` تلقائيًا. لا ترفع ملف قاعدة البيانات إلى مستودع عام ولا تشارك أسرار الإدارة.

## نقاط API
- `POST /api/register` — حقول JSON: `name`, `email`, `password`, و`referralCode` الاختياري.
- `POST /api/login` — `email`, `password`.
- `GET /api/me` — يتطلب `Authorization: Bearer <token>`.
- `GET /api/referrals` — يتطلب تسجيل الدخول.
- `GET /api/admin/users` — يتطلب رأس `x-admin-key`.
- `GET /api/health` — فحص الحالة.

## قبل النشر العام
- انشر عبر HTTPS على استضافة موثوقة واضبط الأسرار من لوحة الاستضافة، لا تضعها داخل الكود.
- أضف سياسة خصوصية وشروط استخدام ووسيلة استعادة كلمة المرور والتحقق من البريد وحماية من إساءة استخدام الدعوات.
- لا تفعّل جمع أموال أو استثمارات أو وعود أرباح أو مدفوعات مكافآت قبل مراجعة قانونية مستقلة والتأكد من الترخيص والامتثال في الجزائر. لا تُخزّن بيانات البطاقات أو كلمات مرور الخدمات المالية.
- مفتاح الإدارة الحالي آلية تقنية أولية فقط؛ للإطلاق الحقيقي يلزم نظام إدارة وصلاحيات وتدقيق أقوى.
